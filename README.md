# 📦 Amazon Order Data Analysis

## 📌 Project Overview

This project analyzes Amazon order data using Microsoft Power BI. The dashboard provides insights into sales performance, order trends, and customer behavior through interactive visualizations.

## 🎯 Project Objectives

- Analyze Amazon order data.
- Understand sales performance and order trends.
- Explore customer insights and purchasing behavior.
- Identify important patterns using data visualization.
- Present meaningful business insights through Power BI dashboards.

## 🛠️ Tools and Technologies

- Microsoft Power BI
- Power Query
- Data Cleaning
- Data Visualization
- Data Analysis
